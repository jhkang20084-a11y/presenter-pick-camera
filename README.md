# 발표자 추첨 카메라

웹캠에 비친 얼굴 중에서 발표자를 무작위로 뽑는 웹앱입니다.
추첨이 시작되면 카메라가 얼굴을 하나씩 확대해 비추다가, 점점 느려지며 최종 발표자의 얼굴에서 멈춥니다.

## 사용법
1. 페이지를 열고 **📷 카메라 시작** → 카메라 권한 허용
2. **🎲 발표자 뽑기** (또는 `Space`)
3. 다음 발표자는 다시 버튼 / `Space`, 화면 클릭 또는 `Esc`로 전체 화면 복귀, `F` 전체화면

- 지금 화면에 보이는 얼굴 중에서만 추첨하며, 한 번 뽑힌 사람은 모두 한 번씩 뽑힐 때까지 다시 뽑히지 않습니다.
- 얼굴이 잠깐 가려져도 약 2.5초간 같은 사람으로 유지되고, 같은 사람이 움직여도 중복으로 세지 않습니다.
- 작거나 먼 얼굴, 어두운 환경을 위해 화면을 여러 구역으로 나눠 검사하고 밝기를 보정합니다.
  단, 얼굴이 크게 가려지거나 매우 어둡거나 멀면 감지되지 않을 수 있습니다.

## 개인정보
카메라 영상은 브라우저 안에서만 처리되며(MediaPipe Face Detector), 얼굴 이미지나 생체정보를 저장하거나 서버로 전송하지 않습니다.

## 요구 사항
- Chrome / Edge 최신 버전, 웹캠
- https 또는 localhost 에서 열어야 카메라 권한이 동작합니다 (GitHub Pages 주소 권장)
- 첫 실행 시 얼굴 인식 모델을 인터넷에서 불러옵니다
